## 📋 Overview

**Techcps-Task-Manager** is a desktop task and project management application developed using **C# and the .NET Framework**.

The application provides a centralized workspace where users can create tasks, organize projects, monitor progress, and manage important work through a graphical interface backed by **SQL Server**.

Whether you're maintaining a personal task list or managing multiple project activities, Techcps-Task-Manager focuses on keeping workflows simple, structured, and easy to track.

## 🚀 Getting Started

### 📋 Requirements

Before running the application, make sure your system has:

- 🖥️ **Windows 10 or later**
- 💻 **Visual Studio 2019 or newer**
- 🗄️ **SQL Server Express or higher**
- 📦 **.NET Framework 4.7.2 or later**
